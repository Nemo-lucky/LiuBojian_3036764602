## 报告要回答的两个问题

原论文：1992年新泽西最低工资从4.25提高到5.05美元，是否减少快餐店就业？

我们的拓展：政策后的就业变化，在公司直营店与非直营店之间是否不同？本文把非直营店简称为加盟店，但数据只记录公司所有权指示变量，没有加盟合同细节。

## 复现的主要结论

Table 2核对88个已发表数值，82个一致；Table 3核对80个，66个一致；Table 4按表注设定核对18个，16个一致。这些比例不是评分，也不说明因果设计正确。

原始410家店中，两期就业变化有效384家；再按工资规则筛掉27家，Table 4为357家，其中NJ290、PA67。六家永久关店保留且后期就业为零。

平衡样本的州间变化差异为2.75个FTE。Table 4缩小到共同样本后，NJ系数为2.33，加入品牌和所有权后为2.30。不能把它们理解成NJ自己的新增人数，也不能断言所有模型都显著。

## 拓展的主要结论

主回归为：就业变化 = 截距 + NJ + 直营店 + NJ×直营店 + 品牌控制。

控制品牌后，加盟店的NJ−PA变化差异约2.64，直营店约1.70。两者之差为−0.94，HC3标准误2.64，近似p值0.721，95%区间[−6.14，4.25]。

结论是没有足够证据确认两类店反应不同，不是两类店效果相同。区间较宽，数据仍容许较大的正负差异。GAP和384家样本补充也没有显著交互项；不需要为显著性更换题目。

所有权非随机分配，品牌控制不能解决全部经营差异。只有一期政策前数据，不能直接检验分组平行趋势。可能的资金或决策机制只作为动机，不能写成已被验证。

## 已明确保留的差异

- Table 2的85.5%与原文85.2%并未强行统一。装修店的诊断处理可以解释均值与标准误，不能解释原文t。
