# Local workflow page: reviewer quick start

The page runs on your own computer. No Codex installation, AI account or API key is needed. Python 3.10 or newer is required; the exact Windows/Python environment tested is recorded in docs/teacher_download_validation.json. Other operating systems have not been tested.

## Download and set up

Download or clone the complete project, then open a terminal in the folder containing code/run_all.py, code/local_app.py and README.md. On Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe code/local_app.py
```

The browser opens automatically. Keep the terminal open. Alternatively, after setup, double-click 启动本地页面.bat; it selects the project virtual environment automatically. Do not switch to a different system Python after installing dependencies into .venv.

## Choose the input and run

Obtain Package 01 public.csv through authorized course access. Place it in data/raw/01_DID/data/public.csv within the project for automatic detection, or choose your local file on the page. No data or code edits are needed. This tool expects the specific Card and Krueger course dataset, not arbitrary minimum-wage datasets.

Click Run all analyses. The page runs Table 2, Figure 1, Table 3, Table 4 and the ownership extension, then verifies the recorded analytical sources, all39 outputs and the selected input. When Verified appears, inspect result cards and stage tabs, open English stage notes, preview figures, or download numeric CSVs.

Verify existing results checks the current files without recalculating. Changed or missing files cause verification to fail. First use in a fresh project requires Run all analyses because no current run exists.

## Data and outputs

Original input files are not edited. Browser-selected data are copied locally under logs/ui_inputs, which is excluded from Git. The page serves aggregate results only; restricted raw and store-level processed data must not be published. The four processed datasets are regenerated under data/processed and require an authorized teaching-team access arrangement if supplied separately.

The interface uses the Python standard library; analytical dependencies are installed from the project requirements. No internet is needed after installation and obtaining the input. All generated outputs are local. A GitHub repository link is a download/review entry point, not a hosted analytical website. Existing aggregate outputs may be included for review; use Run all analyses to regenerate them for your current input and code.

Press Ctrl+C in the service terminal to stop after analysis finishes. If port8765 is occupied, run `.\.venv\Scripts\python.exe code/local_app.py --port 8766`. Check the page execution log and logs/workflow.log on failure. Computation and file-integrity checks do not establish causal assumptions or exact agreement with every published value. The narrative PDF report is not automatically regenerated by this workflow.
